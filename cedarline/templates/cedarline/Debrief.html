What Was This Study About?

This study examined how app-based investment fraud tactics influence decision-making. Specifically, we were interested in how features of an investment interface affect people's choices about reinvesting money and paying withdrawal fees.

What Was Simulated

The following elements were part of the study design:

  • Return on initial investment — Some participants saw a 0% return and some saw a 35% return on the initial Rs 100. This was randomly determined and was intended to study how initial returns affect subsequent decisions.
  • Social proof cues — Some participants saw a ticker showing fictional investor activity (e.g., "Aarav K. just reinvested"). These messages were entirely fictional and not based on any real data.
  • Urgency timer — Some participants saw a countdown timer labelled "VIP tier window closes in…". This timer was non-binding and had no effect on the study or outcomes.
  • Withdrawal processing fee — The Rs 200 processing fee is a common tactic in real app-based investment fraud (sometimes called a "recovery scam"). In this study, all balances were virtual and no real money was involved.
